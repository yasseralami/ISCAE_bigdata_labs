Agrégations & KPI – Détection fraudes
15 min
À faire
📊 Pipeline d'agrégation MongoDB
Alternative moderne à MapReduce. Permet de grouper, filtrer, trier, calculer des sommes/moyennes directement dans la base.
Montant total des transactions
BankDB> db.transactions.aggregate([{ $group: { _id: null, totalAmount: { $sum: "$Transaction Amount" } } }])
{ "_id" : null, "totalAmount" : 1254789.32 }
Montant moyen par type de transaction
BankDB> db.transactions.aggregate([{ $group: { _id: "$Transaction Type", avgAmount: { $avg: "$Transaction Amount" } } }])
Transfert → 1520.45, Dépôt → 890.20, Retrait → 640.33
Top 5 des comptes qui envoient le plus d'argent
BankDB> db.transactions.aggregate([
{ $group: { _id: "$Sender Account ID", totalSent: { $sum: "$Transaction Amount" } } },
{ $sort: { totalSent: -1 } },
{ $limit: 5 }
])
ACC_8923 → 52000 MAD, ACC_4512 → 48700 MAD ...
Transactions échouées par appareil
BankDB> db.transactions.aggregate([
{ $match: { "Transaction Status": "Failed" } },
{ $group: { _id: "$Device Used", totalFailed: { $count: {} } } }
])
iPhone → 23, Android → 41, Desktop → 12
Transactions frauduleuses de montant > 1000 MAD
BankDB> db.transactions.find({ "Fraud Flag": "True", "Transaction Amount": { $gt: 1000 } })
⚠️ 47 documents (à analyser manuellement)
Taux d'échec (%)
BankDB> db.transactions.aggregate([
{ $group: { _id: "$Transaction Status", count: { $count: {} } } },
{ $group: { _id: null, total: { $sum: "$count" }, failed: { $sum: { $cond: [ { $eq: [ "$_id", "Failed" ] }, "$count", 0 ] } } } },
{ $project: { failureRate: { $multiply: [ { $divide: [ "$failed", "$total" ] }, 100 ] } } }
])
failureRate : 7.2%
Q2 : Quelle méthode d'agrégation remplace MapReduce dans les versions récentes de MongoDB ?
✅ Le pipeline d'agrégation (aggregate()) est plus performant et plus souple que MapReduce.
❌ La bonne réponse est aggregate() avec ses étapes ($group, $match, etc.).

MapReduce moderne avec PyMongo (agrégations)
15 min
À faire
🐍 Pourquoi un script Python ?
Les commandes shell sont parfaites pour l’exploration, mais dans un projet réel, on automatise avec un langage de programmation. PyMongo est la librairie officielle de MongoDB pour Python.
⚠️ MapReduce obsolète
Depuis MongoDB 5.0, map_reduce() est dépréciée. Le pipeline d’agrégation (aggregate()) est plus performant, plus flexible et plus simple à écrire.
Le script mapreducemongo.py est disponible dans le dépôt GitHub du cours : voir le fichier. Il contient les mêmes agrégations que la section précédente, mais exécutées depuis Python.
1
Ouvrir Google Colab
Aller sur colab.research.google.com et créer un nouveau notebook.
2
Importer le script depuis GitHub
Dans une cellule, exécuter la commande ci‑dessous.
Télécharger le script
!wget https://raw.githubusercontent.com/yasseralami/ISCAE_bigdata_labs/main/assets/mongdb/mapreducemongo.py
✅ mapreducemongo.py downloaded
3
Modifier l’URI de connexion
Ouvrir le fichier dans l’éditeur de Colab (double‑clic dans l’explorateur de fichiers). Remplacer la ligne uri = "..." par votre propre URI MongoDB Atlas (incluant votre mot de passe).
4
Exécuter le script
Dans une nouvelle cellule, taper %run mapreducemongo.py ou copier-coller le contenu du fichier.
Résultats attendus : total des montants par type de transaction, moyenne, top 5 émetteurs, taux de fraude. Les sorties doivent correspondre à celles de la section 5.
Pourquoi l’agrégation (aggregate()) remplace-t-elle MapReduce dans MongoDB ?
✅ MapReduce est obsolète depuis MongoDB 5.0. L’agrégation est plus rapide, plus lisible et mieux intégrée.
❌ MapReduce est déprécié, et l’agrégation offre de meilleures performances et une syntaxe plus claire.
